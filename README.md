Predict employee attrition using Machine Learning with an interactive Streamlit dashboard. This application helps HR professionals identify employees who are at risk of leaving the organization by analyzing demographic, job-related, and performance attributes.

# 📌 Project Overview

Employee attrition is a major challenge for organizations because replacing employees is costly and time-consuming. This project leverages the **CatBoost Classifier** to predict whether an employee is likely to leave the company based on multiple personal and professional factors.

The application provides:

- Employee Attrition Prediction
- Attrition Probability Score
- Risk Gauge Visualization
- Employee Analytics Dashboard
- Feature Importance Analysis
- Employee Profile Comparison
- Batch Prediction using CSV Upload

---

# 🎯 Problem Statement

Employee turnover negatively impacts productivity, recruitment costs, and organizational performance. Predicting employee attrition allows HR departments to take proactive actions to improve employee retention.

# 📈 Machine Learning Model

**Algorithm Used**

- CatBoost Classifier

### Why CatBoost?

- Handles categorical features efficiently
- High prediction accuracy
- Less preprocessing required
- Reduces overfitting
- Excellent performance on tabular datasets

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/DineshM2006/employee-attrition-prediction.git
```

Move into the project folder

```bash
cd employee-attrition-prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Streamlit application

```bash
streamlit run app.py
```
